## 2026-07-09 · 项目知识网络支持回滚

**摘要**：项目详情抽屉新增「回滚到上一版」，可将当前知识网络恢复为最近归档版本（不新增版本号）。

### 用户可见

- **入口**：项目详情抽屉 → **项目知识网络** 区块。
- **回滚到上一版**（琥珀色按钮）：当存在至少一个归档版本时，具备发布权限的用户可见。点击后确认，即可将当前版撤销并恢复为**最新归档版**（例如 v12 → v11）。
- **恢复此版本**：在版本下拉里选中某一归档版后，可出现「恢复此版本」，效果与回滚相同，但目标为所选归档版。
- **权限**：与「上传 HTML 覆盖」一致——**admin / core**（Worker 侧校验）；访客账号无此操作。
- **确认文案**：会提示「当前版将被撤销；此操作不会新增版本号」。

### 接口 / 后端

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/projects/{projectId}/knowledge-network/rollback?userId=` | 回滚至归档版 |

请求体（可选）：

```json
{ "archiveVersion": 11 }
```

- 省略 `archiveVersion` 时，默认回滚到**最新归档版**（`project_knowledge_network_versions` 中 `version` 最大的一条）。
- 成功响应含 `meta`、`removedVersion`、`removedVersionDisplay`、`message`。

**回滚逻辑（不升版本号）**：

1. 从 R2 读取目标归档 HTML（`v{n}.html`）。
2. 将 `current.html` 写回为该归档内容，并刷新附录 D 版本台账。
3. 更新 D1 `project_knowledge_networks`（`version` / `version_label` / `updated_by` / `changelog` 等）。
4. 从归档表删除已恢复的那条记录；删除被撤销当前版在 R2 上的 `v{bad}.html`（若存在）。

**运维脚本**（与 API 共用同一套逻辑）：

```bash
cd api-worker
npx tsx scripts/rollback-kn-to-archived-version.ts <projectId> <archiveVersion>
```
